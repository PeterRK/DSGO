# Binomial Heaps
![](../images/BinomialHeap.png)

　　A binomial heap is an odd creature. It is based on a forest of trees arranged in increasing order of node count.  
　　These trees are highly regular, and each contains `2<sup>k</sup>` nodes (`k` is the order of the tree). Lined up together, they form a base-2 polynomial.
```go
type node[T cmp.Ordered] struct {
    key   T
    level uint8          //marks the subtree level
    peer  *node[T]
    child *node[T]
}
type Heap[T cmp.Ordered] struct {
    list *node[T]       //list of subtrees
    top  *node[T]       //points to the heap top
    size int
}
```

## Merging
　　Merging the trees themselves is easy. What really matters is merging the base-2 polynomials. One may do this by inserting term by term: whenever two terms of the same order are encountered, take them out and combine them into a term of higher order.

　　If each tree is thought of as one binary digit, then the merging process looks very much like doing addition: trees of the same order collide, produce a carry, and continue upward to the next order.
```go

func (hp *Heap[T]) merge(list *node[T]) {
    knot := fakeHead(&hp.list)
    for list != nil {
        a, b := list, knot.peer
        if b == nil || a.level < b.level {      //insert
            list, a.peer = a.peer, b
            knot.peer = a
        } else if a.level > b.level {           //skip
            knot = knot.peer
        } else {                                //merge same order
            list, knot.peer = a.peer, b.peer    //detach from the list

            if a.key > b.key {
                a, b = b, a
            }                                   //combine
            b.peer, a.child = a.child, b
            a.level++

            a.peer, list = list, a              //the first term in list may be out of order, but it does not matter
}   }   }                                       //because it cannot have higher order than knot.peer
```

## Push & Pop
　　Pushing into a binomial heap means merging a one-element heap into the existing heap, and its average complexity is only `O(1)`.
```
Let f(x) be the number of carries produced when 1 is added to every base-2 polynomial of size 0 to x-1, then f(2x) = 2f(x) + 1
Clearly f(1) = 0, so by induction f(x) = x - 1
```
　　Popping has to deal with the subtree containing the heap top. Once the root of that subtree is removed, the remaining child list is a reversed binomial heap. We reverse it again and merge it back into the main heap.
```go
func (hp *Heap[T]) Pop() T {
    if hp.IsEmpty() {
        panic("empty heap")
    }
    hp.size--
    key := hp.top.key

    knot := fakeHead(&hp.list)
    for knot.peer != hp.top {
        knot = knot.peer
    }
    knot.peer = knot.peer.peer              //remove the original heap-top node

    hp.merge(reverse(hp.top.child))         //reverse the residual list and merge it back
    hp.top = hp.list
    if hp.list != nil {                     //locate the new heap top
        for pt := hp.list.peer; pt != nil; pt = pt.peer {
            if pt.key < hp.top.key {
                hp.top = pt
    }   }   }
    return key
}
```
　　An extra `top` pointer is maintained here, so reading the heap top can be done in `O(1)`. The price is that after every pop or merge, the new minimum root must be scanned out again.

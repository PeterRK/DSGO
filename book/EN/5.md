___
　　A heap, sometimes also called a priority queue (not a perfectly precise statement), is a common logical structure.

　　Its name reflects two characteristics of the structure:

　　• Viewed as a whole, it forms a pyramid-like stacked structure, with more elements on lower layers than on upper layers.

　　• Viewed vertically, it is formed by many ordered chains flowing together, and each element does not really care about its horizontal neighbors.

```
                 1                       1  1  1  1  1  1
             /       \                   |  |  |  |  |  |
          2             5         <=>    2  2  2  5  5  5
        /   \         /   \              |  |  |  |  |  |
      5       4      6     8             5  5  4  6  8  8
     / \     / \    / \   / \            |  |  |     |  |
    9   7       6        9   8           9  7  6     9  8
```
　　Therefore, a heap is good not at answering "where is a certain element?" but "which element should be popped next?" The differences among the following sections lie mainly in how they maintain this converging structure, and whether they are willing to optimize specifically for merge operations.
